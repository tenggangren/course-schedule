# 二年级课外课表

一个给家人使用的静态课表 H5 应用，手机竖屏 / 微信打开友好。

## 在线访问

https://tenggangren.github.io/course-schedule/

纯静态页面，**无需登录**，任何人打开即用；打开自动定位到今天并高亮当日课程。

**周中（周一 ~ 周五）** · 放学后 16:30–20:30

| 时间 | 课程 |
| --- | --- |
| 周二 19:00–20:30 | 豆神语文（线上直播） |

| 时段 | 周六 | 周日 |
| --- | --- | --- |
| 上午 08:00–12:00 | 英语（线下班 08:00–09:00） | 全天自由 |

空白时段留白，可自行补充安排新课外班。

## 技术

- 单文件原生 HTML / CSS / JS，无框架、无后端、无外部依赖
- 部署于 GitHub Pages，代码改动推送后自动更新

## 更新方法

修改 `index.html` 后提交推送到 `main` 分支，GitHub Pages 约 1 分钟自动构建上线，链接不变。
